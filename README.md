# SSOK 여비정산 - GitHub Pages

이 폴더의 `index.html`을 GitHub 저장소에 올려 GitHub Pages로 배포하면 됩니다.

## 동작
- 기존 AHK의 문구와 핵심 계산식을 그대로 유지
- 출발지/도착지/경유지 장소 자동 검색
- 좌표 기반 주행거리 자동 산출
- 자가용 선택 시 오피넷 날짜별 유가 자동 조회 시도
- 휘발유/경유/LPG는 오피넷 원자료의 소수 둘째 자리까지 표시
- 거리·유가 재산정은 현재 숫자로만 재계산
- 여비 계산 및 인쇄는 브라우저에서 수행
- 기존 `ssok.ini` 대신 브라우저 `localStorage`에 기본 입력값을 저장
- GitHub Pages 정적 환경에서 동작하도록 외부 API를 브라우저에서 호출

## 중요
GitHub Pages는 서버 없이 실행되므로 AHK의 WinHTTP처럼 타 사이트를 직접 우회해서 호출할 수 없습니다.
그래서 장소/거리 조회는 브라우저용 공개 API를 사용하고, 오피넷 조회는 직접 호출을 먼저 시도한 뒤 공개 웹 프록시를 통한 조회를 보조로 사용합니다.
프록시가 차단되거나 오피넷 페이지 구조가 변경되면 유가 자동조회가 실패할 수 있습니다.

## 배포
1. GitHub 저장소를 만듭니다.
2. `index.html`을 저장소 루트에 올립니다.
3. Settings → Pages → Deploy from a branch → `main` / `/ (root)`를 선택합니다.
4. 생성된 GitHub Pages 주소로 접속합니다.
